# UT70 Power Lab

Windows 64 位桌面监控大屏，通过配套 `ATK_UT70DLL.dll` 连接正点原子 UT70。

## 功能

- 实时显示电压、电流、功率曲线，以及 Wh、Ah、阻值、D+、D− 数据。
- 按 USB 仪表上传的数据更新读数，不连接设备时显示等待状态。
- 查看设备序列号、硬件版本、当前界面、通讯 PIN 和采样频率。
- 连接后逐项查询设备信息，等待对应回包，超时自动再试一次；未返回的信息显示“未响应”，可点击“设备与活动”右上角的“刷新信息”重试。刷新失败时保留已收到的信息，活动日志会显示具体失败项目。
- 设置 4、10、50、200、500、1000 SPS 采样频率，切换 UT70 监控界面，重置计数。
- 执行快充协议自动检测，显示识别结果和设备返回的电压能力。

曲线和即时读数最多每秒刷新 20 次，电压、电流、功率、能量和电量读数使用 150 毫秒平滑时间常数；阻值、D+ 和 D− 等辅助读数每秒更新一次，峰值文字每秒更新一次，状态摘要只在状态变化时更新，设备采样率独立设置。最近接收点数和无效数据数量可悬停在“最近活动”上查看。接收数据使用固定容量缓冲，保留最近 60 秒；曲线按像素数量压缩绘制，并保留分段最小值与最大值。卡片峰值按原始有效样本统计，不依赖界面刷新频率。非有限的电压、电流、功率读数会计入“无效”数量，并从曲线排除。

动态文字缓存到内存后在双缓冲内统一绘制，文字变化不调用原生标签的 `SetWindowText`。文字和 KPI 小曲线使用不透明底色及独立双缓冲，避免局部刷新反复绘制父容器；显示内容相同的文字和 KPI 主读数不会重复请求重绘。

## 大屏操作

- 点击 V、I、P 切换曲线，用旁边的选择器显示最近 10、30 或 60 秒。
- 将鼠标移到曲线上查看接收时刻和读数。时间轴使用电脑接收时间，DLL 未提供单点硬件时间戳。
- 按 F11 或点击“全屏”进入大屏，按 Esc 退出。
- 超过 2 秒未收到数据时显示“数据超时”；断开后保留最后读数，重新连接会开始新的统计。
- 协议检测后，青色表示收到通过结果，橙色表示检测未通过，灰色表示本轮未收到结果。
- 电压、电流、功率、能量、电量和阻值按数值大小自动选择 μ、m、基本单位、k、M、G 前缀，例如 `0.0000123 A → 12.300 μA`、`0.0125 Ah → 12.500 mAh`、`4700 Ω → 4.700 kΩ`。峰值单独选择单位，零值沿用基本单位。
- 图表按整个可见范围选择统一单位，坐标轴和悬停读数使用同一倍率；主卡片与图表可以因显示范围不同而使用不同前缀。

单位换算与主读数平滑只影响显示，接收缓冲和峰值统计仍使用 DLL 返回的原始基本单位。

## 运行

1. 将 UT70 连接到电脑，并确认设备驱动正常。
2. 双击 `start.bat`。首次运行或源码有更新时自动编译；没有更新时直接启动。重复启动会尝试显示已经打开的窗口。
3. 点击“连接设备”。退出程序时会自动断开。

程序使用 64 位 .NET Framework 4.0 和随目录提供的 UT70 DLL。编译产物位于 `bin\Release`；该目录中的 EXE 需要与 `ATK_UT70DLL.dll` 及生成的 EXE 配置文件放在一起。配置文件允许 .NET 加载这份带有 Windows 下载标记的配套 DLL，源 DLL 本身不会被修改。

也可以在 Visual Studio 中打开 `UT70Dashboard.csproj`，使用 x64 配置生成。
如果 IDE 提示缺少 .NET Framework 4.0 Targeting Pack，可先使用 `start.bat` 或 `build.bat`，它们直接调用系统自带的 64 位 Framework 编译器，无需安装 .NET SDK。

程序运行时若出错，会显示提示并在 EXE 旁的 `logs` 目录保存详细错误。源码更新后若提示无法替换文件，请先关闭正在运行的大屏，再执行 `start.bat`。

## 开发检查

运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\checks\run.ps1`，可检查自动单位切换及边界、缓冲容量、尖峰保留、无效数据、并发接收、窗口初始化、局部绘制隔离、连续刷新和常规/4K 尺寸布局。连续绘制检查包含 200 次更新、每次 50 个样本，检查动态文字不重放父容器绘制、背景不残留，以及圆角像素完整。该检查使用合成数据，不连接 USB、不发送设备命令；渲染图位于 `bin\checks`。这不能替代实机协议和屏幕显示验证。
